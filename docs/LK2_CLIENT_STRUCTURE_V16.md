# LK.2 — управление клиентами, проектами и сайтами

Версия: `2026.08.02.16`

## Назначение

LK.2 превращает существующий фундамент таблиц клиентов в полноценную рабочую структуру личного кабинета.

## Иерархия

- клиент;
- один или несколько проектов клиента;
- отдельный набор сайтов у каждого проекта;
- отдельные ID Яндекс Метрики и Яндекс Вебмастера у каждого сайта.

## Возможности

- список и карточка клиентов;
- создание и редактирование клиента;
- назначение ответственного менеджера;
- назначение пользователей клиентского кабинета;
- создание и редактирование проектов;
- архивирование проектов;
- создание, редактирование, архивирование и сортировка сайтов;
- хранение нескольких ID Метрики и Вебмастера на одном сайте;
- журнал изменений структуры;
- серверная проверка прав на клиента и проект.

## Роли

- администратор и модератор управляют всеми клиентами;
- менеджер работает только с назначенными ему клиентами;
- клиентский пользователь видит только связанные с ним данные без права изменения.

## Совместимость

- требуется установленная версия `2026.08.02.15`;
- `index.php` не изменяется;
- интерфейс подключается через существующие `assets/app.js` и `assets/app.css`;
- существующий пункт «Клиенты» используется повторно, а при его отсутствии создаётся динамически;
- структура таблицы `projects` определяется во время работы, поэтому создание проекта совместимо с накопительными версиями схемы;
- старый Node.js не вызывает ложный откат;
- повторная установка не создаёт дубли.

## Вне этого патча

Синхронизация компаний, контактов и проектов из Bitrix24 выполняется в блоке BF.1 после завершения LK.1–LK.4.

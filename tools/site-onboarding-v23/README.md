# Unified site onboarding v23

Staged after stable 2026.08.03.22. Adds a single site form for Bitrix24 company websites, local site creation, Yandex Metrika counters, Yandex Direct client/campaign binding, and Yandex Webmaster host IDs. A new URL is appended to the Bitrix24 company WEB field without removing existing values. Local data remains saved if Bitrix24 update fails.

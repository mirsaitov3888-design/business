# Версия 2026.08.02.2

Автоматическая диагностика после установки системных обновлений.

Компоненты:

- `SystemDiagnosticsBridge.php` запускает существующий единый диагностический агент;
- `/diagnostics/` открывает сохранённые отчёты по администраторской сессии или защищённому токену;
- `system_updates` хранит только статус, краткую сводку и имя отчёта;
- полный JSON остаётся в хранилище диагностического центра;
- `latest.json` продолжает использоваться автоматической синхронизацией с GitHub.

Установщик содержит сжатое ядро с двумя проверками SHA-256 и выполняет резервное копирование изменяемых файлов.
